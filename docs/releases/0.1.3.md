Fixes images that rendered blank or with incorrect colors, and the remaining warnings from the official Obsidian release checks.

- Bundles PDF.js's JPEG 2000, JBIG2, and ICC color-profile decoders inside `main.js`. Before this, JPEG 2000, JBIG2, and CCITT fax images in a PDF rendered blank, and images with ICC color profiles showed uncorrected colors. The page opened normally and no error appeared. The decoders are the unmodified WebAssembly files from `pdfjs-dist` 6.4.299, embedded as base64 so the installation is still the same three files; the release check verifies the embedded bytes match. They run locally and make no network requests.
- Removes an unnecessary type assertion from PDF table-of-contents handling and enables the corresponding local lint rule.
- Replaces named white and black CSS colors with equivalent hex values. Appearance and reading behavior are unchanged.

The vault-enumeration and clipboard recommendations describe capabilities used by Reading Desk. The plugin lists PDFs for the document picker and Markdown paths for template suggestions; legacy export cleanup checks Markdown notes for links. Copy writes passage text to the clipboard and does not read clipboard contents. See the README for details.

Requires Obsidian desktop 1.14.4 or newer. Runtime verification covers Linux.
