# Keyboard shortcuts and commands

## Reader keys

These single keys work while a Reader tab is active. They pause while you type in a text field, so they don't clash with Obsidian's own hotkeys. Tooltips show the key beside each button.

| Key | What it does |
| --- | --- |
| H | Toggle highlight mode |
| N | Highlight the selection and open its section in the book note. If a highlight's popup is open, open that highlight's section. Otherwise open the book note. |
| A | Toggle the book note |
| T | Open the table of contents |
| G | Focus the page number field |
| + or = | Zoom in |
| - | Zoom out |
| 0 | Fit width |
| Delete or Backspace | Delete the highlight whose popup is open. A notice offers Undo. |
| 1 to 9 | In the selection popup, pick the swatch in that position |

## Commands

Open the command palette and search for "Reading Desk". Every command can have a hotkey under **Settings → Hotkeys**.

| Command | Where it works |
| --- | --- |
| Open PDF in Reader | Anywhere |
| Open PDF in Obsidian's normal viewer | Anywhere |
| Toggle book note | Anywhere |
| Toggle highlight mode | Anywhere |
| Open book note | Reader tab |
| Highlight selected PDF passage | Reader tab, with text selected |
| Highlight selected PDF passage and write about it in the book note | Reader tab, with text selected |
| Zoom in, Zoom out, Reset zoom | Reader tab |
| Show table of contents | Reader tab |
| Toggle dark pages for this PDF | Reader tab |

## Mouse shortcuts

| Action | What it does |
| --- | --- |
| Ctrl/Cmd and wheel | Zoom around the pointer |
| Right-click the highlighter button | Choose the highlight mode's color |
| Right-click the book note button | Open the book note in the other place, once |
| Right-click the page colors button | Choose page colors for this PDF |
